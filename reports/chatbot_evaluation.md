# Grounded assistant evaluation

One deterministic configuration tested on 60 fixed questions across six held-out properties. Exact expected-fact checks passed: 60/60. Mean measured local response latency: 0.000024 seconds. External API cost: \$0. Cases include property identity mismatch, missing flood data, bedroom/bathroom attributes, prices, forecasts and current-availability distinctions.

Question set, expected values, full responses and timings: artifacts/evaluation/chatbot_cases.json. Matching expected substrings is a narrow factual test, not evidence of unrestricted conversational competence. No LLM credentials were supplied or paid calls made. The four LLM configurations in the full prompt remain unevaluated. Do not claim a five-chatbot comparison.
